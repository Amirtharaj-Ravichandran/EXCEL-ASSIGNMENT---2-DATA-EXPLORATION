# EXCEL-ASSIGNMENT---2-DATA-EXPLORATION
This project demonstrates Excel-based data cleaning and transformation, including handling missing values, correcting inconsistencies, removing duplicates, splitting and merging columns, applying number/date formatting, and using conditional formatting to improve data quality and prepare the dataset for analysis.

Objectives:
Handle missing values in the dataset
Correct inconsistent text formats and spelling errors
Identify and remove duplicate records
Split and merge columns for better data structure
Apply appropriate number and date formatting
Use conditional formatting to highlight important information
Prepare a clean and analysis-ready dataset

Dataset:
Column - 	Description
Product ID	- Unique product identification information
Product Name -	Name of the product
Brand Name -	Brand associated with the product
Quantity -	Quantity of the product
Category -	Product category
Price	- Product price

Data Cleaning & Transformation:
Missing Value Handling -
Missing values in the Price and Category columns were identified and appropriate methods were considered to handle incomplete information. 
Data Standardization -
Inconsistent Product Name formats and Category spelling errors were identified and corrected using Find and Replace. 
Duplicate Removal -
Duplicate rows were identified based on the complete row data and removed to improve dataset quality. 
Data Transformation -
The Product ID was split into Manufacturing Date and Country Code. The Brand Name and Product Name were merged into a new Product Brand column. 
Number & Date Formatting -
The Price column was formatted as currency, and the Manufacturing Date was formatted as DD-MM-YYYY. 
Conditional Formatting -
Conditional formatting was applied to the Price column using data bars or color scales. A custom rule was also used to highlight the Electronics category. 

Deliverables:
The repository contains the cleaned Excel workbook, documentation, and screenshots demonstrating the major cleaning and transformation activities required by the assignment

Tools Used:
Microsoft Excel,
Find & Replace,
Remove Duplicates,
Data Transformation,
Number & Date Formatting,
Conditional Formatting,

Conclusion:
The project demonstrates practical Excel skills in data cleaning, standardization, duplicate removal, transformation, formatting, and visual highlighting. The completed process improves the quality, consistency, readability, and usability of the dataset for further data analysis.
